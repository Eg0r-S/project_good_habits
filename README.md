# Персональный трекер полезных привычек
Приложение для автоматического учёта и визуализации статистики ежедневных привычек — удобное решение для пользователей ПК без навыков программирования.

## 🚀 Возможности
- Добавление/редактирование/удаление привычек в список
- Подсчёт серии ежедневного выполнения привычек
- Расчёт процента выполнения за последние 30 дней

## 🛠 Технологии
- Язык программирования: Python
- Фреймворки и библиотеки (все стандартные): os, sys, json, tkinter, datetime.

## 📦 Установка
1. Скачать интерпретатор python с официального сайта python.org
2. Скачать архив и распокавать их него папку Dist.
3. Сохранить эту папку, где вам удобно на ПК. (При желании можно создать ярлык на исполняемый файл .exe)
 
## Запуск:

1. Перейти в папку, где храниться main.exe (или где ярлык)
2. Запустить файл (или ярлык)
