# Персональный трекер полезных привычек
Приложение для автоматического учёта и визуализации ежедневных привычек — удобное решение для пользователей ПК без навыков программирования.

## 🚀 Возможности
- Добавление привычек
- Подсчёт серии выполнения привычек
- Расчёт процента выполнения за последние 30 дней

## 🛠 Технологии
- Язык программирования: Python
- Фреймворки и библиотеки (все стандартные): os, json, tkinter, datetime.

## 📦 Установка и запуск
1. Клонировать репозиторий:
   ```bash
   git clone https://github.com
   ```
2. Установить зависимости и запустить:
    Установить python
   ```bash
   cd /путь_к_файлу_main.py
   python3 main.py
   ```
